Costume Breakdown · รายละเอียดชุด

  • 👗
    ชุดไหล่เปิด / Off-shoulder bodiceเสื้อผ้าไหมขาวเปิดไหล่ธรรมชาติ แถบอกขลิบทองบน-ล่าง
  • 🌙
    คอร์เซ็ตกำมะหยี่ไพลิน / Velvet corsetรัดรูปช่วงเอว ปักเส้นทองแนวตั้ง 8 แนว + ขลิบทองขอบบน-ล่าง
  • ☀️
    ตราอาถรรพ์ / Arcane sun emblemดาวทองกลางอก ล้อมด้วยรังสี 8 แฉก
  • ⛓️
    โซ่ทองที่เอว / Gold waist chainโซ่ทองคาดเอวเฉียง + สายห้อยหน้า + จี้พระจันทร์เสี้ยวทอง
  • 🩰
    กระโปรงสั้นหลายชั้น / Multi-layer skirtชั้นบนจีบกรมท่า → ระบายผ้าไหมขาว → ลูกไม้ขาวชั้นใน ยาวลดหลั่น
  • ⭐
    ดาวทองห้อยชาย / Hanging gold starsดาวทอง 8 ดวงห้อยเส้นด้ายทองรอบชายกระโปรง + ดาวประดับบนผ้ากรม
  • 🎀
    โบว์ราชวงศ์หลังเอว / Royal back ribbonโบว์น้ำเงินใหญ่ 2 ชั้น ปมไพลิน + คริสตัล ปลายชายรัดห่วงทอง
  • 🧤
    แขนเสื้อถอดได้ / Detached sleevesผ้าไหมขาวบานปลาย ปลายแขนน้ำเงินขลิบทอง + การ์ดแขนน้ำเงินฝังอัญมณี
  • 👑
    มงกุฎจันทร์เสี้ยว / Crescent tiaraจันทร์เสี้ยวทอง 3D กลางหน้าผาก + แถบทอง + ยอดแหลม + พลอยไพลิน-คริสตัล + ดาวกลุ่มดาวในผม
  • 🧦
    ถุงน่องต้นขา / Thigh-high stockingsผ้าไหมขาว แถบปักทอง + สายรัดถุงน่องน้ำเงิน (garter)
  • 👠
    รองเท้าไพลิน / Sapphire shoesหนังเงาน้ำเงินเข้ม metallic เข้าชุดคอร์เซ็ต
  • ✨
    ออร่าเวท / Celestial auraดาวทอง-คริสตัลลอยโคจรรอบตัว + วงเวทสวรรค์ 3 วงหมุนใต้เท้า (ปิดในภาพสตูดิโอ)
