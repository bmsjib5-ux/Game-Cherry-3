# 🍒 Cherry Pet — น้องเชอร์รี่เดินอยู่บนเดสก์ท็อป

น้องเชอร์รี่ตัวเดียวกับในเกม ออกมาเดินเล่นอยู่บนหน้าจอ Windows เดินไปมาเอง
ยืนพัก กระโดด นอนหลับ อุ้มย้ายที่ได้ คลิกเล่นได้

ใช้ `Rig` ตัวเดียวกับเกม 2D (`maple/src/rig.js`) และสีชุดจาก `CLASS_OUTFIT`
ในข้อมูลกลางชุดเดียวกัน จึงเปลี่ยนอาชีพได้ครบทั้ง 8 แบบและหน้าตาตรงกับในเกมเป๊ะ

## รันบนเครื่องตัวเอง

ต้องมี [Node.js](https://nodejs.org) ก่อน

```bash
cd desktop-pet
npm install
npm start
```

## ทำเป็น .exe แจกได้

```bash
cd desktop-pet
npm install
npm run dist
```

ได้ไฟล์ในโฟลเดอร์ `dist/` สองแบบ

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `Cherry Pet Setup x.y.z.exe` | ตัวติดตั้งปกติ เลือกโฟลเดอร์ได้ มีลัดในเมนู Start |
| `CherryPet-portable-x.y.z.exe` | ไฟล์เดียวจบ ไม่ต้องติดตั้ง ก๊อปใส่แฟลชไดรฟ์พาไปได้ |

**ต้อง build บน Windows** (หรือใช้ CI ที่เป็น Windows) — electron-builder สร้าง .exe
ข้ามแพลตฟอร์มได้ไม่ครบเรื่อง โดยเฉพาะการเซ็นโค้ดกับไอคอน

## วิธีเล่นกับน้อง

| ทำอะไร | ได้อะไร |
|---|---|
| ปล่อยไว้เฉย ๆ | เดินไปมาเอง สลับยืนพัก กระโดด และนอนหลับ (มี 💤) |
| คลิกซ้ายที่ตัว | จับหัวเล่น — กระโดดตอบพร้อมขึ้น ❤️ |
| ลากตัว | อุ้มย้ายที่ ปล่อยแล้วร่วงลงพื้นเอง |
| คลิกขวาที่ตัว | เปิดเมนู |
| คลิกไอคอนเชอร์รี่ในถาดระบบ | เรียกมาหาเมาส์ |
| คลิกขวาไอคอนถาดระบบ | เปลี่ยนอาชีพ · สั่งหยุด/เดินต่อ · เริ่มพร้อม Windows · ออก |

ตำแหน่ง อาชีพ และสถานะหยุด/เดิน ถูกเซฟไว้ กลับมาเปิดใหม่อยู่ที่เดิม

## ทำไมใช้หน้าต่างเล็กเท่าตัวละคร ไม่ใช่หน้าต่างใสเต็มจอ

desktop pet ทำได้สองแบบ ที่นี่เลือกแบบ "หน้าต่างขนาดเท่าตัว แล้วขยับตัวหน้าต่างเอง"

- **แคนวาสเล็กจิ๋ว** กิน GPU/แบตน้อยกว่าหน้าต่างใสเต็มจอ 1920×1080 มาก
- **ไม่ต้องทำ click-through** — ที่ว่างรอบตัวไม่มีหน้าต่างบังอยู่แล้ว จึงคลิกไอคอน
  บนเดสก์ท็อปหรือหน้าต่างข้างหลังได้ตามปกติ ไม่ต้องยุ่งกับ `setIgnoreMouseEvents`
  และการเช็คว่าเมาส์อยู่บนตัวละครหรือไม่ทีละพิกเซล
- **ลากตัวละคร = ย้ายหน้าต่าง** ตรงไปตรงมา

## โครงสร้าง

```
desktop-pet/
  main.js              โปรเซสหลัก: หน้าต่าง ถาดระบบ ไฟล์เซฟ IPC และขยับหน้าต่าง
  preload.js           สะพาน IPC แบบจำกัดสิทธิ์ (contextIsolation เปิด, ไม่มี nodeIntegration)
  src/brain.js         สมองของ pet: ท่าทาง ฟิสิกส์ การสุ่มพฤติกรรม (ไม่พึ่ง Electron)
  src/pet-view.js      ฝั่งภาพ: วาด Rig บนแคนวาสโปร่งใส เล่นท่าตามสถานะที่ได้รับ
  build-pet.mjs        รวมโค้ดเป็น pet.html + สร้างไอคอนจากโค้ด
  pet.html             สร้างอัตโนมัติ ห้ามแก้มือ
  assets/              สร้างอัตโนมัติ: tray.png, icon.ico
```

`brain.js` แยกออกจาก `main.js` เพื่อให้ทดสอบได้จริง — ฉีดตัวสุ่มที่มี seed เข้าไป
แล้วเดินเวลาเองทีละสเต็ป จึงตรวจได้ครบทุกท่าโดยไม่ต้องเปิดหน้าต่างและไม่ flaky
`main.js` จึงเหลือหน้าที่เดียวคือคุยกับระบบปฏิบัติการ

## เรื่องที่ต้องระวัง

- **`PET_W` / `PET_H` มีอยู่สองที่** (`main.js` กับ `src/pet-view.js`) ต้องตรงกัน
  ถ้าไม่ตรง renderer จะรายงานกลับมาและขึ้นคำเตือนใน console ตอนเปิด
- **เวลาที่ป้อนเข้าสมองต้องเป็นเวลาที่ผ่านไปจริง** ไม่ใช่ค่าคงที่ต่อ tick
  ถ้าใช้ค่าคงที่แล้ว `setInterval` ถูกหน่วง (เครื่องงานหนัก โน้ตบุ๊กประหยัดพลังงาน)
  pet จะเดินสโลว์โมชัน สั่งนอน 10 วินาทีจะนอนจริง 40 วินาที
  และต้องมีเพดาน (`MAX_STEP_MS`) กันการกระโดดข้ามจอตอนเครื่องตื่นจาก sleep
- **ตอนนี้เดินอยู่บนจอหลักจออันเดียว** — คำนวณพื้นจาก `getPrimaryDisplay().workArea`
  ถ้าต่อหลายจอ น้องจะไม่ข้ามไปจออื่น (ยังไม่ได้ทำ)
- **ท่าใหม่ต้องไม่ล้นกรอบหน้าต่าง** — `fitInFrame()` ใน `pet-view.js` วัดกรอบภาพจริง
  แล้วดันกลับเข้ากรอบให้เอง อย่ากลับไปใช้ออฟเซ็ตเป็นตัวเลขคงที่ (เคยพลาดตรงนี้แล้ว
  ท่านอนกวาดออกนอกกรอบเหลือให้เห็นแค่ปลายเท้า)

## ที่ทดสอบไว้แล้ว และที่ยังไม่ได้ทดสอบ

ทดสอบบน Linux + Xvfb (คนละแพลตฟอร์มกับที่ใช้จริง):

- สมอง 18 เคส แบบกำหนดผลได้ — ทุกท่าเกิดขึ้นจริง เด้งขอบจอ กระโดดแล้วตกลงพื้น
  อุ้มแล้วปล่อยร่วงลงพื้น สั่งหยุดแล้วนิ่ง เปลี่ยนความละเอียดจอแล้วกลับมายืนบนพื้น
- ฝั่งภาพ 17 เคส — แคนวาสโปร่งใสจริงทั้งสี่มุม ทุกท่าอยู่ในกรอบไม่ถูกตัด
  แยกคลิกกับลากถูก เปลี่ยนอาชีพได้ ไม่เรียกอินเทอร์เน็ต
- แอปจริง 8 เคส — หน้าต่างเดินไปมาบนหน้าจอ ยืนติดพื้นเสมอ ไม่หลุดขอบจอ
  เซฟตั้งค่าเป็นระยะ นาฬิกาเดินตามเวลาจริง ไม่แครช

**ยังไม่ได้ทดสอบ** (ทำในเครื่องนี้ไม่ได้ ต้องลองบน Windows จริง):

- ความโปร่งใสระดับหน้าต่างบนเดสก์ท็อป Windows (ตั้งค่าตามที่ Electron กำหนดไว้แล้ว
  แต่บนเครื่องที่ปิด Desktop Composition หรือไดรเวอร์จอมีปัญหา อาจเห็นเป็นกล่องดำ
  ถ้าเจอ ให้ลองเพิ่ม `app.disableHardwareAcceleration()` บรรทัดแรกของ `main.js`)
- ไอคอนถาดระบบและเมนูคลิกขวาบน Windows
- `npm run dist` สร้าง .exe และตัวติดตั้ง NSIS
- การเริ่มพร้อม Windows (`app.setLoginItemSettings`)
